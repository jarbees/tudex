# TUDex

An unofficial, student-developed companion app for TU Darmstadt students, built for iOS and Android using Kotlin Multiplatform.

## Highlights

- View your courses and their information
- See your exams, grades, and grade statistics at a glance
- Register for multiple exams at once
- Keep your timetable automatically synchronized with TUCaN
- Check your Athene-Card balance
- Browse the menus of university canteens
- Find buildings using an interactive map

## Privacy & Security

- TUDex does not operate any own backend.  
- Authentication credentials and tokens are stored locally using platform-specific secure storage  
- TUDex stores data locally and communicates directly with TU Darmstadt / Studierendenwerk Darmstadt services

## Disclaimer

**This is an independent app made by students and is not affiliated with or endorsed by TU Darmstadt.**

While every effort is made to ensure accuracy and reliability, errors cannot be ruled out.  
For important actions, particularly registrations, always verify their successful completion in the official TUCaN portal.

## Installation

Public downloads are not yet available. You can build the app from source using the instructions below.

## Building

### iOS

1. Install Xcode.
2. Open the `.xcodeproj` file in `iosApp/`.
3. Select a target device and build the app.

### Android

1. Install Android Studio.
2. Open the project's root directory.
3. Select a target device and build the app.
